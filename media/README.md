# Safeguard On launch media

`safeguard-on-intro.mp4` is an original 26-second, 1080×1920 text-card introduction
to the Uzbek technology page. Audio is a locally synthesized instrumental bed;
there is no spoken narration and no claim to use a trending song. Caption copy
is in `safeguard-on-intro-caption.txt`.

This is an introduction written for the page, not a news report or a product test.
It can be served using a commit-pinned raw GitHub URL for the first Metricool
schedule. Preserve that URL until Metricool has ingested/published the media.
